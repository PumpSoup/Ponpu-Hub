# 🎧 Ponpu — Official Landing Page & Discography

Modern neon dark glassmorphic landing page for **Ponpu** (@ponpu.ratta) — Pop / Indie Rock Artist.

## ✨ Features
- **Hero Spotlight:** Latest Single *"ม้ายเจ ม้ายใจ"* (Released 30.09.2026) with authentic album artwork sleeve
- **Discography:** Track list with high-res cover art and direct streaming buttons for Spotify & YouTube Music:
  - *Unidentified (ยืนยันตัวตน)*
  - *ขวัญอ่อน (Pretended)*
  - *Happy So Bad (อกหักแบบหล่อ ๆ)*
- **Platforms & Socials:** Instant links to YouTube Channel, Instagram, TikTok, and Facebook
- **Interactive Booking / Contact:** One-click copy email `bargameshop@gmail.com`
- **Responsive & Lightweight:** Pure HTML + CSS + JS in a single static file, zero dependencies, blazing fast load times
